## 环境备注（本机）

- Bash 工具本次运行的 shim 初始化失败（`dirname: command not found`），PATH 中缺少
  `/usr/bin` 等目录，`ls/find/head/wc/mkdir/grep` 均不可用；`git` 可用。
  解决办法：命令前加 `export PATH="/c/Program Files/Git/usr/bin:$PATH"`。
  另注意 `find` 会被解析为 Windows `FIND.EXE`，加入上述 PATH 后恢复正常。
