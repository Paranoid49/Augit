## 结论

`editor-page-partial-2026-10-17.md` 中“两侧项目树宽度已同为 360 CSS”的表述**不被现有原始 PNG 支持**。重新测量同一对图后：

- 实际 `editor-page-360-nobottom/actual-panel.png`（2881×1717）左侧工具窗口右缘约在物理 x=700–711；扣除工具轨后约 **360–362 CSS**。

- 参考右侧还存在约 68 物理像素（≈39 CSS）的竖向通知/AI 侧栏，实际没有该结构。该右栏也被计入 6.082% 全图差异。

```python
from PIL import Image
import numpy as np
for name, path in [
    ('ref', 'artifacts/pixel-followup-2026-10-17/reference-width-final/screen.png'),
    ('act', 'artifacts/pixel-followup-2026-10-17/editor-page-360-nobottom/actual-panel.png')]:
    a = np.asarray(Image.open(path).convert('RGB')).astype(np.int16)
    band = a[200:1400]
    g = np.abs(band[:, 3:, :] - band[:, :-3, :]).max(axis=2)
    frac = (g > 3).mean(axis=0)
    print(name, [(x + 3, round(float(frac[x]), 3)) for x in range(len(frac)) if frac[x] > 0.75])
```
