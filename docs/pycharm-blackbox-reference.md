## 6. Changes 与 Diff

这是最容易被静态截图掩盖的交互基线。

| 操作 | 实测结果 | 保持不变 |
| --- | --- | --- |
| 首次单击 Changes 文件 | 只选中行，不打开 Diff | 复选状态、提交信息、编辑区、面板尺寸和滚动 |
| 按 `Enter` 或执行“显示 Diff” | 打开并激活 Commit Diff 标签 | Commit 列表和其他标签 |
| 双击 Changes 文件 | 打开并激活 Commit Diff；后续单击其他文件仍更新同一比较，未保留原文件比较 | Commit 全部状态；补充实测见 `PY-COMMIT-FOLLOW-01` |
| 已有 Commit Diff 时单击其他文件 | 后台更新同一比较标签；Diff 激活时原位更新 | 普通文件正文和全局布局 |
| 单击文件复选框 | 只改变提交选择 | 行选择、Diff 请求和提交信息 |
| 连续选择多个文件 | 只显示最后一个有效请求 | 过期结果不得覆盖最新结果 |
| Diff 加载超过 150 毫秒 | 只在正文区域显示加载状态 | 工具窗口、标签条、分隔位置和列表 |

2026-09-10 连续复核纠正了此前“Changes 双击后固定到该文件”的结论：从无比较状态直接双击，随后改选仍更新同一 Commit Diff；显式 `Pin Tab` 后也继续跟随文件选择。此前把普通文件预览的保留语义套用于 Commit Diff，证据不足，不能继续标记为 PyCharm 实测。UX 已将该条降级为待确认，差异和待确认方案见 `PY-COMMIT-FOLLOW-01`；普通文件与搜索预览的规则不从本次结果推导。

## 8. 弹层、对话框与返回

| 类型 | 进入方式 | 退出方式 | 返回后恢复 |
| --- | --- | --- | --- |
| 非模态弹层 | 快速打开、分支选择、右键菜单、当前文件搜索 | `Esc`、取消或选择动作 | 原窗口结构、焦点、选择和滚动 |

## 9. 可执行探索记录格式

| 字段 | 必须记录的内容 |

| 证据等级 | 实测、同构推导或产品裁剪；不允许省略。 |

## 10. 核心工作流证据契约
