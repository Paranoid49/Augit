# 外部可见 500ms 的定义与采样（2026-10-17）

## 定义

“外部可见完成”取**最后一次 `window/modal-uncover` 应答结束**：此时后台刷新已把遮盖撤下，更新后的内容具备被用户看到的条件。这个定义不依赖 25ms 轮询，也不把“请求已排队”当作可见。

严格计时仍从**外部文件写入前**到该撤盖应答结束；两者使用同一事件时间线。

## 结果

| 批次 | 定义下的外部可见 | 备注 |
| --- | ---: | --- |
| 改动后 A（GDI） | 495.7ms | 轻量录屏/无额外全窗负载 |
| 改动后 B（GDI） | 496.5ms | 同上 |
| 改动后 C（DDA） | 481.0ms | 同上 |
| 改动后 D（GDI） | 488.5ms | 同上 |
| AF55 全主窗录制 | 541.1ms | 全窗 GDI 录制负载，非轻量基线 |

- 四批轻量正常入口样本均 **<500ms**；25ms 外部轮询的 502/504/506ms 不作为定义。
- 全主窗 116fps 录制的首轮为 541.1ms，说明录制负载会把外部可见推过 500ms；不能用录制负载样本宣称正常使用超时。

## Git 状态

- 外部分支 checkout 的命令完成到界面 branch 更新 125ms。
- 冲突外部解决同步 230/241/411ms，均 <500ms。

## 限制

- 该定义是“撤盖完成”，不是逐帧首内容像素；首个内容帧需要高帧率外部采集且会引入录制负载，当前没有无扰动的逐帧真值。
- 未覆盖每个 Present、所有 Git 元数据、全部 DPI。严格宿主计时与定义在轻量样本中一致；录制负载样本只作为上界。
