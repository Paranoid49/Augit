# Augit 1.0.0 预发布候选已知限制

本文对应公开发布的 `1.0.0-rc.2` 预发布包。构建源提交、产物哈希与复验命令见[发布清单](release-manifest-1.0.0-rc.2.md)。它只登记本候选实际验证到的边界，不把未验证项写成通过，也不把已知缺陷包装成“后续优化”。更细的历史证据见[发布收口台账](release-closure-2026-10-24.md)与其中链接的专项记录。

## 1. 发布身份与签名

- 这是 **1.0.0-rc.2 公开预发布候选**（GitHub Pre-release），不是正式 1.0。正式 1.0 仍需 RC 的真实日常使用观察与用户裁决。
- 2026-10-25 的旧 rc.2 冻结构建（`8643b9e`）**从未公开上传**，其原始哈希无法复核。本次公开资产由包含 Windows 10 22H2 多显示器/DPI 修复的源码重新构建；构建源提交与每个资产的 SHA-256 以[发布清单](release-manifest-1.0.0-rc.2.md)和 Release 内的 `SHA256SUMS.txt` 为准。
- Augit 可执行文件与安装包**没有 Augit 自身代码签名**。Windows SmartScreen 可能提示“未知发布者”；企业环境可能按策略阻止运行。
- 安装器下载的 .NET/WebView2 微软运行时包会校验固定哈希与 Microsoft Corporation 数字签名；这不等于 Augit 自身已签名。

## 2. 平台范围

- 产品支持 Windows 10 22H2 x64 与 Windows 11 x64。
- **Windows 11 x64** 已完成主界面、安装/升级/卸载、便携包、屏幕阅读器和性能基线验证。
- **Windows 10 Pro 22H2 `10.0.19045.6456` x64** 已在双显示器实机完成验证：2560×1440 + 1920×1080、100%/125%/150%/175%/200% 缩放、真实鼠标跨屏拖动、混合 DPI 启动、负坐标显示器布局、模拟显示器热插拔、深色 1024×640 窄窗，以及 rc.2 源码重建包的便携运行与静默安装。详见[22H2 多显示器 DPI 修复与扩展验证](win10-22h2-multimonitor-dpi-fixes-2026-10-26.md)。
- 尚未验证：干净虚拟机/全新系统安装；真实缺少 WebView2 的安装流程；三块及以上显示器；物理拔插显示器（已由用户移出本次验收范围）；更多 DPI 组合与显示器排列；Narrator 完整会话、JAWS、Braille；足够时长的真实日常使用观察。
- 真实鼠标坐标校准覆盖 Windows 10 22H2 双屏与 Windows 11 单屏条件；其他显示器拓扑仍可能暴露未登记的几何差异。

## 3. 视觉与像素目标

- 历史整窗零容差像素结果保持原样：**共享功能页整窗像素合格 0 张，页面级语义/状态配对 50 组**。本候选**没有**达成“全部共享页面像素合格”的原整改目标。
- 与 PyCharm 2026.2.1 仍存在标题栏、标签条、底部 Git、状态栏、代码字族回退、字体栅格等差异；这些是持续改进项，不冒充通过。
- 已批准范围差异不算缺陷：无右侧 42 CSS 工具轨、简化自定义 Settings、简洁 xterm 终端、无三栏冲突编辑器、无 AI 入口、无内置文本编辑/保存。
- 系统窗口阴影顶部/底部强度弱于参考，已登记为已知差异。
- 启动 1 秒、低内存为持续目标，不是本候选的否决门槛，也未写成通过。

## 4. 状态同步与性能

- 外部文件刷新：2026-10-24 与 2026-10-25 两批同轮 gdigrab/ddagrab 各 10 轮，屏幕首内容 **236–293ms**，宿主应用 **161–207ms**。历史无 CDP gdigrab 曾出现 **611/552/624ms** 三次慢样本；合计 20/20 未复现，但慢点仍**未归因**，保留为未闭环性能风险。
- 本地 Git checkout：命令结束后分支可见 **117–152ms**，完整应用 **201–232ms**（3 轮）。
- Settings 冷开历史目标 500ms：3 轮全新进程实测 491.4/451.1/567.2ms，**未连续达成**；2904ms 历史慢样本未复现；500ms 上限、正常/异常路径已由 3 个受控单测覆盖（3/3），关闭路径沿用 29.1–89.7ms，仍无自然超时样本。
- 80,000 行/约 3MB 文本开启软换行会退回完整行 DOM：页面级构建 **3.62–9.78s**（本轮重跑 4.371s）、真实外壳首测 **5.23s**，生成 80,000 个行节点。之后滚动、Find、Go to Line、全选、关闭标签可用，关闭软换行恢复窗口层。大文件建议保持软换行关闭；本阶段不实现可变行高虚拟化。
- Diff 有实现上限：文本文件 10MB 上限，Diff 两侧各 10MB 且生成结果 20MB；超大 Diff 只显示状态/截断说明，不展开全文。参考在 8.74MB/92,001 行时可完整显示，这是能力差异，不写成同态。
- 搜索 15 秒超时只在**受控慢 rg 条件**下验证；自然慢盘、超大仓库的真实超时性能未实测。
- 终端简洁 xterm 与参考 Reworked 命令块存在已批准差异；资源回收已有专项证据，但未覆盖所有长时使用。

## 5. 大文本与可访问性

- 大文本保留全文逻辑层（选择、复制、Find、Go to Line、全文行数）；视觉窗口只挂当前窗口行。
- 可访问树只暴露**当前窗口行 + 全文行数**；离屏全文不同时存在于可访问树，屏幕阅读器连续全文朗读仍受限。已实测强制 accessibility + UIA 枚举（80,000 行 168ms/138 后代），并明确拒绝恢复导致约 100 秒布局阻塞的全文 `pre` 方案。
- 已完成真实 NVDA 2026.2 会话：小文件全文可读；2,001 行大文本的活动行原先只播报位置、不读正文，已修复为播报行号与正文，并可键盘到达末行。**纯 OS 键盘会话**又验证小文件 5 行全文、2,001 行到第 1504/1523/2000 行、80,001 行抽样到第 61/80000 行；未发现新的焦点/行号/播报缺陷。可访问树仍只有窗口内约 25–30 行，离屏全文不能连续朗读；这是虚拟化能力边界，不是 ARIA 属性问题。
- Narrator 仅确认可执行文件存在，未做完整会话；JAWS/Braille 未安装，不作通过结论。

## 6. Git、认证与冲突

- 真实前台 OS 鼠标 Continue Rebase 已在两文件 rebase、外部删除+编辑暂存场景通过；Skip/Abort、反向解决顺序、二进制冲突未用真实鼠标复验。
- Push 认证测试只覆盖专项记录中的具体协议/凭据 helper 场景（认证失败、成功、非快进后外部解决并重试），不代表所有网络、代理和凭据方案。
- Augit 不保存凭据；认证行为取决于本机 Git Credential Manager、SSH agent、代理和终端环境。
- 不提供 Force Push、Git 子模块、平台接口或内置 Git Console；失败原因与重试入口按已批准形态呈现。

## 7. 安装与分发

- 便携包解压启动、必需文件/许可证、web 资源一致性、版本与关闭清理已验证。
- 本机以管理员完成 **0.1.0 安装 → 1.0.0-rc.2 覆盖升级 → 静默卸载**：退出码均 0；PATH 逐字恢复且未重复、右键菜单/开始菜单清理、用户设置哈希不变、.NET/WebView2 共享运行时未变；RC 启动 631ms、退出 0。
- Windows 10 22H2 实机完成 rc.2 源码重建包的便携运行与静默安装：安装器检测到系统缺少 .NET 10，显示中文确认提示；确认后下载 `30,604,768` 字节的 .NET 10.0.11 安装包、校验并安装，随后完成 Augit 安装；安装版从 `C:\Program Files\Augit\Augit.exe` 启动正常。
- 安装器在**真实缺少 WebView2** 的机器上的确认、联网下载、取消、下载失败和重试路径未实测；本机 WebView2 齐全。干净虚拟机/全新系统安装也未验证。
- 不提供包含完整运行时的离线安装包；无自动更新。
- 公开 Release 只包含便携 zip、安装器与 `SHA256SUMS.txt`；原始截图、日志和本机验收报告不在公开仓库或 Release 中。
