Augit 界面视觉稿

基于 PyCharm 2026.2.1 New UI 的布局、密度、状态转换和 Git 工作流，删除 Augit 不支持的 IDE 能力后重新平衡界面。

01 项目与文件查看主框架、项目树、Markdown 和 Git 日志并存。 02 普通文本查看只读文本、行号、当前文件查找和跳转。 当前文件查找错误无效正则提示在浮层内显示，正文保持。 当前文件查找进行中超过 150 毫秒后局部提示，输入与关闭始终可用。 当前文件查找超时保留查询、正文和阅读位置，可改词继续查找。 当前文件查找大字号输入、结果文字扩展，开关图标保持固定尺寸。 跳转行输入紧凑模态、输入焦点和右侧确认动作。 03 Markdown 预览原文、预览和左右对照。 04 JSON 格式化严格 JSON 的只读格式化结果。 JSON 原文同一文件双段切换，原文保持只读。 JSON 格式错误顶部行列提示可点击定位，格式化禁用。 主框架大字号 · 浅色40px 界面文字、13px 等宽正文，容器按字高扩展。 主框架大字号 · 深色文字区域扩展，图标尺寸保持。 05 图片预览受支持图片的缩放和尺寸信息。 06 不可预览文件超限、非法 UTF-8 和不支持格式摘要。 07 提交工具窗Changes、复选、Amend 与提交信息。 08 工作区 Diff变更选择后的稳定双栏差异视图。 09 Git 历史引用树、提交图、筛选和详情。 历史 Diff 加载局部占位与取消比较。 历史 Diff 失败失败原因保留在比较区。 历史 Diff 取消保留历史选择，可再次打开重试。 10 文件历史与 Blame限定路径的历史和逐行归属入口。 11 引用比较工作区、分支、标签与提交比较。 12 分支与标签分支搜索、创建、切换和比较弹层。 13 Stash 管理查看、应用、弹出和删除。 14 ResetSoft、Mixed、Hard 的影响确认。 15 Worktree 管理创建、打开和安全移除。 16 远端管理远端名称、获取 URL 与推送 URL。 17 克隆仓库仓库 URL、目标目录和浅克隆。 18 Push提交列表、目标引用和确认。 19 冲突操作会话冲突文件以及实际可用的会话动作。 20 三栏冲突解决当前分支、最终结果和合入内容。 21 快速打开键盘优先、最多 100 个文件。 22 全仓搜索搜索开关、结果和截断状态。 23 内置终端底部按需单会话终端。 24 设置外观、字体、Git 与终端配置。 25 Git 不可用保留文件浏览的降级状态。 26 Git 操作反馈进行中、失败、原因与恢复入口。 27 打开工作区最近目录、选择目录和启动降级状态。 28 初始化仓库非 Git 目录的显式初始化确认。 29 Blame只读正文旁的逐行提交归属。 30 Smart Checkout覆盖风险、临时 Stash 和恢复结果。 31 Rollback完整文件回滚与将丢失 Diff。 32 Git 操作进行中进度、取消和防止重复触发。 33 关闭运行中终端终止前台命令与子进程树确认。 34 搜索截断与超时1000 项上限、停止和已有结果保留。 35 提交空态无变更时保留 Commit 工具窗骨架。 36 Diff 局部加载临时标签与最小更新区域。 37 Push 无远端定义远端入口与禁用的 Push。 38 Stash 管理已有 Stash 的详情、应用、弹出和删除。 39 项目右键菜单路径、资源管理器、终端、刷新和历史。 40 Changes 右键菜单Diff、回滚、文件历史和定位。 41 Git 历史右键菜单提交级操作及危险入口。 42 快速打开空态输入前保持紧凑，结果出现后向下增长。 43 Git 历史复杂提交图真实分叉、合流、HEAD 环和双轨列宽。
