## 2. 本批共享界面修改

- 新增令牌 `--augit-doc-code-block`：浅色 `#F4F7F9`、深色 `#26292C`（深色取方案值）。
- `.markdown-preview pre` 与行内 `code` 的背景改用该令牌；`pre > code` 保持透明。
- 代码块区域实测：两端 y=390–473 完全一致；左缘 754 vs 757（侧栏 3 px）；右缘差来自参考右侧 42 CSS 工具轨（已批准不实现），不是内距差。

## 4. 剩余差异（未通过原因）

1. **底部 Git 选择态不同**：参考未选中提交，右侧显示 `Select commit to view changes`；Augit 默认选中首行并显示 `3 files` 与提交详情。该区域占底部 16.02% 的很大一部分，属状态差异，不能靠容差掩盖。补齐同态需两端同选或同不选；本批未改产品默认选择行为。
2. **参考独有区域**：右侧 42 CSS 工具轨、trial 按钮、Run 配置选择器（`Current File`）、Git Console 标签和额外工具栏图标；按既有裁决不实现，单列排除，但原始整窗计数仍包含它们。
3. **标题栏共享区**：标签圆角/内边距、左侧 chip 与右侧窗口按钮仍有差异；标题栏 48.52% 不能全部归为参考独有。
4. **项目树文字**：根行选中底与参考同为 y=154 起（底部高 1 px）；文件行文字带与参考在 1–2 px 内交错，行高取整与字形栅格不同；根行路径已同文本、同字重。
5. **编辑区文字**：h1/正文/代码仍有字形栅格与 2–3 px 水平差；代码字族回退宽约 16 物理 px（参考 JCEF 回退较窄等宽字体，Augit 固定 JetBrains Mono 11.05 px）。
6. **状态栏**：参考的行列、缩进、解释器等为参考独有或产品差异；共享分段位置仍不同。
