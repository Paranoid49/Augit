# 主窗启动/关闭的白帧边界（2026-10-24，屏幕录制）

> 结论：桌面 30fps 录屏中，主窗从无到有和从有到无均未出现“整窗纯白”帧；启动时
> 最先出现的是正常应用外壳（空编辑器，窗口区域约 87.2% 近白，但不是纯白），
> 关闭时直接切回桌面。该结论只覆盖本批浅色空工作区、单屏和本机 DPI。

## 1. 方法

| 项 | 值 |
| --- | --- |
| 启动 | `tools/start-augit.ps1 -SkipBuild -Workspace <临时仓库> -SettingsFile <隔离设置>` |
| 实例 | PID 16636 |
| 录制 | `ffmpeg -f gdigrab -framerate 30 -video_size 2880x1800 -t 12`，PID 4516 |
| 窗口 | 物理 rect `-12,-12,2892,1728`，最大化；单屏 2880×1800、DPI168 |
| 触发 | 录制开始约 0.5s 后启动；约 6.5s 时 `CloseMainWindow()` |
| 视频 | `artifacts/main-startup-close-2026-10-24/startup-close.mkv` |
| 帧 | 30fps 共 360 帧；PNG 在 `.../frames/` |
| 分析 | 对窗口 rect 裁剪后统计纯白 (`RGB≥248`)、近白 (`≥240`)、均值、与首帧差异 |

## 2. 时间线

| 帧 | 时间 | 内容 |
| ---: | ---: | --- |
| 1–62 | 0–2.07s | 桌面（窗口尚未可见）；桌面本身约 94% 近白，不能当应用白帧 |
| 63–67 | 2.10–2.23s | 桌面/任务栏变化，仍无应用窗口 |
| **68** | **2.27s** | **首帧应用外壳**：标题栏、项目树、空编辑器、Git 加载中 |
| 68–253 | 2.27–8.43s | 应用内容；空编辑器近白约 **87.2%**，不是纯白 |
| 254–257 | 8.47–8.57s | 关闭过渡，窗口开始消失 |
| 258–360 | 8.60–12.0s | 桌面 |

- 首次进程启动到首帧应用外壳约 **1.77s**（录制 0.5s 启动，帧 68 在 2.27s）；
  这不是点击到首内容，也不是可交互耗时。
- 启动/关闭都没有 `white≥0.98` 且窗口已可见的应用帧；帧 47–62 的 99.3% 纯白是
  桌面，不是应用。
- 关闭时没有先闪一帧纯白再消失，也没有保留透明/空窗。

## 4. 边界

- 空工作区、浅色、单屏、最大化；未测深色、多显示器、跨屏 DPI、最小化恢复。
- 屏幕录制包含桌面和任务栏；桌面白色像素已从应用白帧判断中排除。
- 2.27s 是进程启动到首帧外壳的录制时间，不是用户点击到可见/首内容；不能写成性能通过。
- 只证明本批没有整窗纯白帧，不证明任何主题、任何冷启动路径都没有白帧。
- 未做透明通道检查（gdigrab 桌面录制不带 alpha）；系统阴影仍是已知差异。
