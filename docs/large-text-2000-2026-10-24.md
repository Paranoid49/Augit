# 大文件窗口层 2,000 行基线（2026-10-24）

> 结论：按用户要求先在 2,000 行级别验证选择、复制、Find、Go to Line 和滚动，再
> 扩展到 80,000 行 / 22.75MB。2,000 行样本（265,675 字节）在窗口层只挂 33 行，
> Ctrl+A 复制长度/SHA256 与全文一致，Find/GoTo 到第 2,000 行，拖动能自动滚动。

## 1. 样本

- `small.txt`：2,000 行 × 约 120 字符 = **265,675 字节**，超过 200,000 字符虚拟化阈值；
- 正常入口：`start-augit.ps1 -SkipBuild`，临时 Git 仓库 + 隔离设置；
- PID 10912，正常关闭，`pidAlive=false`。

## 2. 结果

| 项 | 值 |
| --- | --- |
| 全文行数 | 2,000 |
| 可见 `.code-line` | 33 |
| 全文 `textLength` | 265,675 |
| Ctrl+A 剪贴板 | **265,675 字节** |
| 剪贴板 SHA256 | `0a426206…d6867acf` |
| 磁盘 SHA256 | 同上 |
| `lengthMatches` / `hashMatches` | **true / true** |
| Find in File | 3/3，定位第 2,000 行 |
| Go to Line | 第 2,000 行，`line 002000 NEEDLE_LAST` |
| 末尾 `lastLine` | 2,000 |
| rowHeight | 22 |

拖动：

| 输入 | `scrollTop` | 剪贴板 |
| --- | ---: | ---: |
| CDP 指针 | 3,226.9 | 22,635 字节 |
| Win32 `mouse_event` | 7,150.3 | 45,910 字节 |

- 报告：`artifacts/large-text-2000-2026-10-24/large-text-normal-entry.json`。
- 2,000 行样本的全文选择、拖动自动滚动、Find、GoTo 均通过；随后同批脚本继续验证
  80,000 行和 22.75MB 预览。

## 3. 可访问性状态

- `a11yLength=0`；
- 仅 `aria-label="Read-only content, 2,000 lines"`；
- 行号 `aria-hidden`，可见窗口行可读；
- **全文可访问树仍未完成**，2,000 行基线也只提供行数摘要，不把本项写成 a11y 通过。

## 4. 边界

- 2,000 行样本是人工生成的等宽行，不是参考 PyCharm 文件；未采参考像素。
- 拖动只持续 1.2 秒，不是拖到第 2,000 行末尾的完整长距离拖动；CDP 与 Win32 都只证明
  自动滚动和选区扩展。
- 未验证 Find 命中在窗口层的高亮像素、反向拖动、块选择。
- 页面级配对仍 50、像素仍 0。

## 5. 复验
